# KLA Hackathon Practice

Python solutions developed while preparing for the upcoming KLA hackathon through a college-level trial event.

## Solutions

- `python sol.py` — milestone 1
- `python sol2.py` — milestone 2
- `python sol3.py` — milestone 3
- `python sol4.py` — milestone 4

## Run locally

Use Python 3.14 from this directory:

```powershell
py -3.14 "python sol.py"
py -3.14 "python sol2.py"
py -3.14 "python sol3.py"
py -3.14 "python sol4.py"
```

Each script reads its corresponding milestone input file from the current directory. Challenge statements and test inputs are intentionally not included.
